## Договорённости о продукте
Demo: бесплатный, синтетический, read-only, 1 группа, 8 тестовых записей, 2 дисциплины. Никогда не отображать данные оригинального `localStorage`.
Pro: персональная настройка, полный журнал, расписание, КТП, Excel, резервные копии, локальное хранение учебных данных.

## Рекомендуемая серверная модель
Учетные записи: `users(id,email,created_at)`
Лицензии: `licenses(id,user_id,plan,status,expires_at,max_devices)`
Привязки: `activations(id,license_id,device_id,last_seen_at,revoked_at)`
Платежи: `payments(id,license_id,provider_id,status,amount,created_at)`
Аудит: `license_events(id,license_id,event,created_at)`

API-контракт:
- `POST /api/account/register` — регистрация с подтверждением электронной почты;
- `POST /api/license/activate` — проверка и привязка к устройству;
- `POST /api/license/refresh` — обновление токена;
- `POST /api/license/deactivate` — отвязка устройства;
- `POST /api/payments/create` — инициирование оплаты сервером;
- `POST /api/payments/webhook` — проверенный webhook провайдера.

Секретные ключи, API-токены оплаты, проверка webhook и выпуск лицензий — **только на сервере**. Для офлайн-работы рассмотреть короткоживущие цифровые подписи Ed25519 с публичным ключом проверки в клиенте. Максимальная длительность без проверки — проектные 30 дней, но безопасное применение без доверенных часов браузера ограничено. При окончании лицензии оставить чтение и экспорт данных.

## Принципы защиты
Не размещать реальные ФИО и учебные данные в публичном GitHub, демонстрационной сборке, исходных шаблонах или логах аналитики. Не загружать журнал и оценки на сервер лицензий. Отдельные origin для демо и Pro предпочтительны, чтобы разделить хранилища и Service Worker. Публичный JavaScript нельзя надёжно скрыть; лицензия усложняет копирование, но не гарантирует абсолютной защиты.

## Важное ограничение резервного копирования
Git-ветка фиксирует исходный код, но **не резервирует** локальное хранилище Safari на iPhone. Перед миграцией, переустановкой или очисткой кэша вручную создать резервную копию JSON в настройках текущей версии и проверить чтение файла.

## Критерии первой итерации
1. Ветка `main` не изменена.
2. `demo/index.html`, `demo/manifest.json`, `demo/sw.js` согласованы.
3. Демо не импортирует и не выводит реальных студентов.
4. Кнопка занятия открывает журнал выбранной дисциплины.
5. Работа офлайн после первого успешного посещения (проверить в браузере).
