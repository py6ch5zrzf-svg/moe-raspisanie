# Моё расписание 9.7

Готовая версия для GitHub Pages и установки на iPhone как PWA. Архив содержит ровно 4 файла: `index.html`, `manifest.json`, `sw.js`, `README.md`.

## Что проверено и исправлено в 9.7
- Исправлена выгрузка **Журнала в Excel**.
- Имена листов Excel теперь автоматически очищаются от запрещённых символов, ограничиваются 31 символом и делаются уникальными — это устраняет сбой при длинных названиях дисциплин/тем.
- В выгрузке журнала добавлена обработка ошибок, чтобы приложение не падало молча.
- Выгрузка **Ведомостей в Excel** сохранена и проверена вместе с журналом.
- Сохранены все функции расписания, ручного добавления занятий, журнала, оценок, ведомостей и Excel.
- Данные из версии 9.6 автоматически переносятся в хранилище 9.7; также поддерживается миграция старых версий.
- Service Worker и кэш обновлены до 9.7.

## Установка
1. Распакуйте архив.
2. Загрузите все 4 файла в корень репозитория GitHub Pages с заменой старых файлов.
3. Откройте сайт и обновите страницу.
4. Если на iPhone отображается старая версия, закройте установленное приложение и откройте сайт заново; Service Worker 9.7 удаляет кэши старых версий.

## Важно
Все данные приложения хранятся локально в браузере. При переходе с 9.6 данные должны быть автоматически перенесены. Рекомендуется перед обновлением сделать резервную копию через «Настройки → Резервная копия базы».
