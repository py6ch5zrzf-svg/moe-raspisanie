# Моё расписание 8.6

Связка: КТП → расписание → занятия → электронный журнал → ведомость.

Изменения 8.6:
- Ведомость фильтруется по группе и дисциплине.
- В журнале список студентов зависит от группы, даты занятий находятся в заголовках, оценки и посещаемость редактируются прямо в таблице.
- В занятии время автоматически берётся из настроек пары, тема — из выбранного КТП; дублирующее ручное поле темы убрано.
- В КТП номер и название темы не вводятся повторно; редактируются часы и тип выбранной темы.
- Студентов можно редактировать.
- Физическая культура допускается в расписании без КТП.
- Excel-импорт расписания автоматически подставляет время пары, если оно не указано.
