# Моё расписание 8.3 — улучшенная версия

Включает 4 рабочие программы и 77 студентов в трёх группах: ЗЧС-01-26, ЧС-02-25, ОПУТ-02-25.

## Новое в 8.3
- импорт студентов из CSV прямо с iPhone;
- CSV-импорт работает оффлайн, без GitHub и без интернета;
- дубли студентов не добавляются;
- новые группы создаются автоматически;
- сохранение данных в памяти телефона (localStorage);
- полный импорт Excel сохраняется.

Для обновления GitHub Pages загрузи `index.html`, `manifest.json`, `sw.js`, `README.md`.
