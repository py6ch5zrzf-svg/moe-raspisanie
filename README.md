# Моё расписание — 4 программы

Это **правильный проект «Моё расписание» преподавателя**, а не приложение для категории C.

В приложении уже заложена структура:
- 4 рабочие программы;
- КТП;
- недельное расписание;
- добавление занятий;
- группы и студенты;
- дисциплины;
- журнал;
- ведомости;
- Excel;
- настройки;
- локальное хранение данных;
- PWA/offline-обвязка для установки на телефон.

## Загрузка в GitHub

Загрузи в репозиторий файлы:
- `index.html`
- `manifest.json`

- `README.md`
