# Моё расписание 9.1

Версия 9.1 собрана на основе стабильной 8.9.

## Исправления
- Сохранение занятий и переход к расписанию сохранены из 8.9.
- Ручной ввод расписания сохранён.
- Добавлена кнопка импорта расписания из Excel прямо во вкладке «Расписание».
- В «Студентах» сохранён фильтр «Показать группу»; дублирующее поле группы при добавлении студента убрано.
- В «Электронном журнале» сохранены рабочие выборы семестра, группы и дисциплины.
- В «Ведомостях» добавлен выбор дисциплины вместе с группой.
- В «Занятии» тема берётся только из КТП; отдельное поле «Тема занятия» удалено.
- «Учебные программы», КТП, рабочий стол и журнал сохранены без лишних изменений.
- Экспорт/импорт JSON переименованы в понятные действия резервного копирования.
