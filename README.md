# Моё расписание 9.8

Обновлённая версия приложения преподавателя с безопасным переносом данных из 9.7 и предыдущих поддерживаемых версий.

## Файлы
- `index.html` — приложение;
- `manifest.json` — PWA-манифест;
- `sw.js` — Service Worker и офлайн-кэш;
- `README.md` — эта инструкция;
- `icon.svg` — значок PWA.

## Главное в 9.8
- данные версии 9.7 автоматически переносятся в новое локальное хранилище 9.8;
- перед обновлением в GitHub создана отдельная резервная ветка `backup-v9.7-before-v9.8`;
- стандартное время первой пары изменено на 09:00–10:30; если пользователь уже менял расписание звонков вручную, его настройки сохраняются;
- при импорте Excel, если есть колонка «Преподаватель», автоматически остаются только строки Леонова Г.А.; файлы без такой колонки по-прежнему импортируются полностью;
- физкультура остаётся в недельном расписании, но не включается в журнал, ведомости и учёт фактических часов;
- темы «Инженерной графики» № 19–30 автоматически относятся ко 2 семестру; пользовательские изменённые темы не перезаписываются;
- в таблице учебной программы теперь виден семестр каждой темы;
- добавлен PWA-значок `icon.svg`;
- Service Worker обновлён до кэша 9.8.

## Исправления, сохранённые из 9.7
- автоматический перенос данных из 9.6, 9.5 и более ранних поддерживаемых версий;
- при переносе больше не удаляется пользовательская дисциплина/занятия «Аварийно-спасательная подготовка»;
- исправлено повторное появление удалённых встроенных студентов после перезапуска;
- импортированные из CSV студенты получают строковые ID и нормально редактируются/удаляются;
- CSV-импорт корректнее обрабатывает кавычки и разделители;
- добавлены видимые вкладки `Группы` и `Дисциплины`;
- удаление группы/дисциплины блокируется, если к ней привязаны данные;
- при удалении студента очищаются его оценки и посещаемость;
- восстановление JSON теперь нормализует и проверяет структуру данных;
- ручное добавление и редактирование занятия предупреждает о пересечениях по времени;
- пересечения занятий выделяются красным в недельном расписании;
- при импорте Excel пересечения подсчитываются и показываются в результате импорта;
- копирование недели пересчитывает семестр по новой дате;
- план в ведомости учитывает выбранную дисциплину;
- общая Excel-ведомость считает средний балл отдельно по дисциплинам, а не смешивает все предметы;
- встроенный КТП `Основы производственных систем` приведён к рабочей программе на 56 часов;
- старые встроенные названия тем `Основы производственных систем` из 9.6 автоматически обновляются только при точном совпадении, пользовательские правки не перезаписываются;
- улучшена печать недельного расписания;
- Service Worker не подменяет `manifest.json` и другие файлы HTML-страницей при офлайн-ошибке;
- библиотека SheetJS (`xlsx`) кэшируется после успешной загрузки и может работать офлайн после этого.

## Обновление с 9.7
1. В версии 9.7 откройте `Настройки` → `Создать резервную копию` и сохраните JSON.
2. Откройте сайт GitHub Pages в Safari при наличии интернета.
3. Закройте приложение с экрана «Домой» и откройте снова. Данные 9.7 должны перенестись автоматически.
4. Проверьте расписание, журнал и одну ведомость. Резервную копию 9.7 храните до завершения проверки.

## Важно про Excel
Основное приложение работает локально. Для импорта/экспорта `.xlsx` используется SheetJS с CDN. В 9.7 Service Worker пытается сохранить эту библиотеку в кэш. Для первого успешного кэширования откройте приложение с интернетом.

## Сброс данных
Кнопка `Сбросить все данные` требует двойного подтверждения и очищает текущую базу и локальные базы предыдущих поддерживаемых версий. Перед сбросом обязательно создайте резервную копию.
