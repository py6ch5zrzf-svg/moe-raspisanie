# Моё расписание 9.0

Стабильная основа 8.4 с аккуратными изменениями 9.0.

## В 9.0
- Сохранён ручной ввод расписания.
- Добавлен/сохранён импорт расписания из Excel.
- В занятии тема берётся из выбранной темы КТП; отдельное поле «Тема занятия» удалено.
- В «Студентах» сохранён фильтр «Показать группу»; дублирующий выбор группы в форме добавления студента удалён.
- В «Ведомостях» сохранён выбор группы и добавлен выбор дисциплины.
- Электронный журнал и рабочий стол преподавателя не менялись по логике пользователя.
- КТП остаётся источником тем и может не требоваться для дисциплин, которым оно не нужно.
- В настройках «Экспорт JSON» переименован в «Создать резервную копию», «Импорт JSON» — в «Восстановить из резервной копии».
