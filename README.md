# Моё расписание 9.4

Исправленная версия приложения преподавателя.

## В комплекте
- `index.html` — основное приложение;
- `manifest.json` — PWA-манифест 9.4;
- `sw.js` — Service Worker с обновлением и очисткой старых кэшей;
- `README.md` — инструкция.

## Исправлено в 9.4
- исправлена ошибка отсутствующего поля темы в форме занятия;
- ручное добавление, редактирование, сохранение и удаление занятий работают с единым типом ID;
- импорт Excel корректно обрабатывает даты Excel, даты `ДД.ММ.ГГГГ` и `ГГГГ-ММ-ДД`;
- импорт Excel использует время пары, если начало/окончание не указаны;
- дубликаты занятий при импорте не создаются;
- физическая культура может импортироваться без темы КТП;
- установка встроенных программ больше не удаляет пользовательские дисциплины и занятия;
- резервная копия, шаблон и отчёт имеют номер версии 9.4;
- Service Worker обновлён до 9.4 и удаляет кэши старых версий;
- старые данные из предыдущих версий мигрируются в хранилище 9.4.
