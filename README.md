# Моё расписание 9.9

PWA для ведения расписания, КТП, электронного журнала и ведомостей.

## Установка
1. Загрузите в корень GitHub Pages четыре файла: `index.html`, `manifest.json`, `sw.js`, `README.md`.
2. Не удаляйте данные браузера перед обновлением: версия 9.9 автоматически переносит данные из 9.8 и предыдущих версий.
3. После обновления откройте приложение заново. При старой странице/кэше обновление Service Worker выполняется автоматически.

## Исправления 9.9
- Исправлена и усилена выгрузка электронного журнала в XLSX.
- Для журнала используется тот же механизм `XLSX.writeFile`, что и для рабочей выгрузки ведомостей.
- Добавлена защита от пустых/неполных занятий и ошибок при расчёте фактических часов.
- Листы журнала получают безопасные уникальные имена Excel.
- Сохранена миграция данных из 9.8 → 9.9.
