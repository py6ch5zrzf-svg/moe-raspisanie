# Моё расписание 8.9

Сборка на основе стабильной версии 8.4 с аккуратным возвратом и расширением функций.

## Основные изменения 8.9
- Сохранена рабочая логика 8.4.
- Рабочее добавление занятий: дата, семестр, пара, дисциплина, группа, кабинет, КТП.
- Время пары автоматически берётся из настроек.
- Ручное добавление занятия из расписания, в том числе кнопкой «+» у дня.
- Импорт расписания из Excel сохраняется; время можно брать из настроек пар.
- Занятия из расписания доступны в журнале.
- Журнал показывает даты занятий по выбранной группе и дисциплине и позволяет вводить оценки и посещаемость.
- Ведомость имеет фильтр по группе и режимы семестра/всего года.
- В студентах сохранён фильтр по группе и добавлено редактирование имени без дублирования группы в форме.
- В КТП номер темы не требуется вводить отдельным полем: при новой теме номер назначается автоматически.
- Физкультура допускается в расписании без обязательной темы КТП.
