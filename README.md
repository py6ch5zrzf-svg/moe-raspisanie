# Моё расписание 8.4

Версия 8.4: КТП → расписание → электронный журнал → ведомость.

## Что исправлено
- Оставлены 4 программы: Основы топографии (48 ч.), Основы производственных систем (56 ч.), Аварийно-спасательная подготовка на высоте (72 ч.), Инженерная графика (120 ч.).
- Убрана обычная «Аварийно-спасательная подготовка».
- Убраны кнопки навигации «Группы» и «Дисциплины»; группы используются внутри «Студенты», расписания и журнала.
- В «Студенты» добавлен фильтр по группе.
- Кнопка «Открыть / изменить» в расписании открывает карточку занятия для редактирования.
- Исправлено сохранение даты: используется локальная дата, без смещения на следующий день из-за часового пояса.
- Исправлено удаление занятия: вместе с занятием удаляются его оценки и посещаемость.
- КТП подставляет тему в занятие автоматически.
- В КТП можно выбирать программу, семестр и тему; часы и тип подставляются из КТП.
- Электронный журнал связан с расписанием: выбираются семестр, группа, программа и конкретное занятие; оценки и пропуски ставятся по студентам.
- Ведомость автоматически считает план/факт часов, оценки и пропуски.
- Обновлена PWA/offline-обвязка.

## Обновление с 8.2
Файлы можно заменить в GitHub Pages поверх старой версии: `index.html`, `manifest.json`, `sw.js`, `README.md`.
Данные приложения из localStorage 8.2 переносятся в 8.4 автоматически при первом запуске.
