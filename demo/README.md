# Моё расписание — Demo 10.0

Это самостоятельный демонстрационный PWA-прототип для будущего коммерческого продукта.

- Доступны: главная, расписание, переход из занятия в журнал, пример журнала, ведомости и обзор Pro.
- Данные синтетические: «Студент 01–08», учебная группа «ДЕМО-01», две дисциплины.
- Только чтение; отсутствуют загрузка реальных студентов, ввод оценок, импорт Excel и обработка платежей.
- Демо не использует localStorage и не обращается к ключу `moe_raspisanie_v9_8`: рабочие данные исходного PWA не трогаются.
- Собственный Service Worker имеет кэш `moe-raspisanie-demo-10-0-0` и не удаляет производственный кэш `moe-raspisanie-9-8-4`.
- Оплата и лицензии **не реализованы**, и приложение об этом сообщает.

## Проверка перед публикацией
1. Развернуть ветку в отдельной тестовой среде HTTPS, не меняя GitHub Pages ветки `main`.
2. Проверить адаптивность на iPhone; вкладки, переход из расписания в журнал и ведомости.
3. Проверить установку на экран «Домой» из Safari.
4. При первом открытии с интернетом убедиться, что файлы закэшированы; затем проверить запуск в авиарежиме.
5. Сверить, что в `demo/` нет реальных ФИО студентов, учебных списков и платежных ключей.
6. Не использовать эту ветку как общедоступную платную систему: это только прототип.

Рабочую версию 9.8.4 защищает ветка `backup-v9.8.4-2026-11-13`. Ветка `main` не изменяется.
