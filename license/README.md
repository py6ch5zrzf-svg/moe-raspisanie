# Лицензирование «Моё расписание» — прототип цифровой подписи

**Не развернуто в продакшене.** Код выпуска и проверки лицензий подготовлен отдельно от пользовательского приложения. Никакой оплаты, выдачи ключей покупателям или блокировки Pro сейчас нет.

## Принцип
- Сервер генерирует персональную лицензию, подписывает её приватным ключом ECDSA P-256 (ES256).
- Клиент `pro/license-verifier.mjs` проверяет подпись с помощью публичного ключа JWK.
- В подписанном токене: `v`, `licenseId`, `subjectId`, `plan`, `deviceId`, `issuedAt`, `notBefore`, `expiresAt`, `offlineUntil` (времена в Unix seconds).
- До `offlineUntil` приложение потенциально сможет работать без интернета. После — обязано запросить обновление с сервера; после `expiresAt` платная функциональность блокируется **с сохранением чтения и экспорта своих данных**.
- Сервер контролирует максимум 2 устройства на лицензию, срок, отзыв и продление. Клиент без сервера не может проверить число устройств.
- Приватный ключ нельзя добавлять в GitHub, PWA, браузерный JavaScript или платёжные формы.

## Тест
Node.js 20+ (проверено на Node 22):

```sh
node license/test.mjs
```

Тест создаёт временную пару ключей в памяти и проверяет корректную лицензию, изменение данных, неверное устройство, неверный ключ, истечение срока и необходимость обновления.

## Ещё не готово для продаж
1. Сервер хранения учётных записей, лицензий, устройств и платежей.
2. Регистрация, аутентификация, проверка вебхуков платёжного провайдера.
3. Защита от перебора кодов, журнал действий, настройки отзыва ключей.
4. Настоящий публичный ключ, хранимый в проверенном конфиге клиента.
5. Интеграция проверки токена в интерфейс Pro и политика при истечении лицензии.
6. Публичные условия лицензии и проверка требований к обработке персональных данных.

**Ограничение:** автономный браузер и локальные часы не дают абсолютной защиты от подделки времени или модификации JavaScript; отзыв лицензии станет виден при следующей проверке с сервером. Цифровая подпись предотвращает незаметную подмену лицензии, но не делает открытый PWA некопируемым.
