# Моё расписание Pro 10.0 — разработка

Тестовая Pro-сборка на основе оригинального `index.html` версии 9.8.4, доступная только в отдельной ветке. **Лицензия и оплата пока не реализованы**. Не публиковать как коммерческий релиз.

## Сделано
- Встроенные реальные ФИО 77 студентов и конкретное расписание за ноябрь удалены из этой Pro-сборки. Новая база пустая.
- Учебные группы и дисциплины добавляются пользователем; четыре учебных КТП доступны как *необязательные* шаблоны по кнопке.
- Фильтр преподавателя в Excel берётся из поля «Настройки → Профиль преподавателя» вместо жёстко заданной фамилии. При пустом поле импортируются все строки.
- В `localStorage` используется отдельный ключ `moe_raspisanie_pro_v10_0` без автоматического переноса из рабочей версии.
- Переход из расписания в журнал, учёт оценок, ведомости, экспорт и резервные копии перенесены из 9.8.4.
- Создан отдельный Service Worker и кэш `moe-raspisanie-pro-10-0-0`; им не очищается кэш действующей версии.

## Ограничения
- Пока нет сервера лицензирования, оплаты, учётных записей и защиты Pro от копирования.
- Публикация на GitHub Pages из ветки `main` **не изменена**. Приложение ещё не проверено на реальном iPhone.
- Кнопка восстановления принимает старую JSON-копию **только по явному действию пользователя**. После переноса потребуется проверить все записи.
- Четыре КТП — готовые примеры; их применимость к другим программам следует проверять.
- Основной публичный репозиторий имеет историю с персональными данными, поэтому публикацию или коммерческое распространение вести только после отдельного аудита приватности. Никакие данные с устройства пользователя в GitHub не переносились.

## Предрелизные тесты
1. Проверить первый запуск: пустые группы, студенты и расписание, личный профиль.
2. Создать группу, студентов, дисциплину, занятие и оценки.
3. Проверить переход из расписания в журнал.
4. Проверить импорт Excel с заполненным и пустым полем ФИО преподавателя.
5. Проверить Excel-экспорт и резервную копию JSON, восстановление на отдельной тестовой базе.
6. Проверить установку Safari → «На экран Домой», офлайн-режим после загрузки с интернетом.
7. Проверить отсутствие доступа к `moe_raspisanie_v9_8` и производственному Service Worker.
8. Только после этого подключать реальное серверное лицензирование.

Для версий: `main` — рабочая 9.8.4, `backup-v9.8.4-2026-11-13` — снимок 9.8.4, `feature/demo-pro-v10` — новые разработки.
